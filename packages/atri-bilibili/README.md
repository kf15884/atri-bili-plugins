# koishi-plugin-atri-bilibili 0.5.6（干净库分发版）

主插件：账号登录/状态、自主候选与选片、独立 API、HDS 剧情桥接、公开网页读取、转发视频识别、QQ 视频卡片、公开互动审计。

账号目标和机器人 ID 默认留空，必须由部署者在 Koishi 实例中显式填写。API Key、Cookie 均为空；不附带真实账号、服务器或人设配置。

- `independent`：自定义 HTTPS API 参考获准共享的 HDS 人设/本人剧情，完成选片、读取、回复、卡片和剧情写回；不执行公开账号写操作。
- `hds`（默认）：通过固定版 HDS 角色意图执行；账号写入依赖各项开关、有效来源与确认。
- `legacy`：兼容旧式推荐；不作为新部署首选。

完整功能、配置和模块说明见源码库根目录 README 与 docs。此库不包含 HDS 核心源码，固定适配 HDS 1.0.1-rc57、Koishi 4.18.11。
