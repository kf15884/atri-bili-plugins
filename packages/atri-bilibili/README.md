保留：要视频“文字候选→HDS挑选→观看→卡片→推荐话”；预看及单条预备视频；本人视频不回卡；B站browserIntents交给观看工具；普通搜索不接管；原有观看记录、预备位、预算、回执与取消规则。

新增：推荐挑选/判断/润色、观看感想与其他Atri插件共用后台模型通道；前台、暂停、原生分段优先。队列取消/超时不强行调用模型；推荐排队后刷新对话。已开始的HTTP不承诺抢占。仍由HDS生成角色文本，不另设人格或模型。
