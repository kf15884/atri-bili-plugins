# 排查

## 收到固定降级句（如“只拿到了部分资料……”）
发 `bili.history`。0.5.6 起结果里写明原因：
- “模型请求失败、超时或未返回可解析JSON”：检查自定义 endpoint/模型、余额、超时；推理模型输出过长时可换非推理模型。
- “草稿未通过证据校验（…）”：模型声称完整看完、已执行账号操作或读到不存在的字幕。可在 HDS 规则里减少这类表述。

## 转发视频后没反应或回了别的视频
0.5.5 起转发视频只评论。若回复“这个分享我没认出是哪个视频”，说明短链解析失败（网络或非官方跳转），可直接发 BV 号。

## “独立工具请求未完成，请查插件状态；未输出远端正文”
这是通用异常兜底，不能据此确认是 API、风控、眼镜还是数据库问题。依次发 bili.history、bili.status、bili.watched；分享前去除私人内容，不发送 Cookie、Key 或完整配置。

不要先删缓存、state.json、防重复账本或 HDS 数据库，也不要为排查重装整套 HDS。平台结果未知时不反复重试写操作。
