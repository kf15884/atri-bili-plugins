# 测试与边界

本Beta执行152项测试，全部通过（详见BUILD-INFO.json）。测试环境为Node24、Koishi4.18.11、HDS1.0.1-rc56、SQLite4.7.0；目标生产部署的rc57未在本轮环境重新验收，不把接口兼容测试当成生产验收。

## 覆盖范围

- API资料、只读白名单、扫码会话、严格URL与QQ卡片解析、SSRF与解压限制。
- HDS/插件两种加载顺序、SQLite原生持久化、开场确认后读取、内存草稿、延迟分享与追问竞争。
- 取消、超时、新任务替换、迟到回调隔离及重启不重放。
- 第二台画面与音频结果、无音频线路降级、错误与超时、健康状态和六小时缓存。
- Beta账号与地址默认空；未配置地址时不建立连接；眼镜依赖包含主插件Beta范围。

运行 `npm test` 通过网络禁止预加载器阻断真实HTTP/fetch；测试显式替身可模拟外部返回。不使用真实账号、Cookie、Token，不请求真实B站、模型或QQ。离线打包、JS语法与升级脚本语法另外验证。

## 已知边界

- 开启第二台只提供若干静止画面与开头一段音频的模型理解，不代表完整播放。第二台服务与模型线路须自行部署与验收。
- QQ回执不等于客户端展示或用户已读；未知投递不自动重发。
- 字幕、音频、模型可用性和QQ实际发送均未在本轮实号测试。
- 生产脚本未执行；其他HDS版本、网络环境与自定义模型仍需自行测试。
- Beta包不承诺比稳定版更可靠，建议先在非生产副本验证。
