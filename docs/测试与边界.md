# 测试与边界

135项本地测试通过，0失败。本轮新增观看节奏状态机、开场绑定、追问合并与竞态保护；保留原API/会话/卡片/分享解析回归。

## 覆盖

- 真实Koishi4.18.11 + HDS1.0.1-rc57 + SQLite4.7.0，两种加载顺序。
- 六组真实HDS观看节奏流程：BV/链接/QQ JSON卡片、无追问倒计时、草稿就绪后追问、生成中追问；实际persistDecision、原生confirmOutgoingDeliveries及分段持久化，模型与外部投递用替身。
- 原即时读取模式的两种HDS加载顺序与三种分享格式；原人设、世界和全局主动联系开关不变。
- 开场前/开场生成后都不读取，必须匹配已确认开场剧本；不确认或不匹配不读取。
- 草稿仅内存，不提前持久化角色发言/记忆/跨会话动作；最终才提交，HDS保持原分段。
- 草稿未就绪追问静默、就绪后提前发送，无追问到时发送；定时器与多次追问竞争只提交/投递一次。
- 普通无关话题不吞掉，相关短句/明确视频内容追问识别；同视频合并、新视频替换、旧开场迟到不取消新任务。
- 暂停、源消息删除、权限撤回、HDS任务代际变动、超时和重启取消；inflight重启unknown，不自动重放。
- API读取失败如实生成一次HDS失败草稿；最终投递未确认不重发。
- 旧Cookie/QR/buvid、严格URL/卡片解析、只读白名单、原卡片与未知投递保护。

真实HDS测试中的模型输出、B站API和QQ传输使用替身；没有请求真实B站、模型或QQ，没有执行生产升级脚本。不能证明真实模型总能遵守开场/草稿格式、真实字幕可用、QQ客户端送达或卡片展示。其他HDS版本需另行验证。

## 已知边界

- 音视频不播放、不下载，无图像/音频输入，字幕缺失时只依据元信息。
- 仅明确单视频的本人私聊；未知XML卡片、多目标、复杂隐含追问不保证支持。群聊和其他人不读。
- 首段HDS投递回执不代表全部气泡已送达，更不代表用户已读；后续分段由HDS自身控制。
- 模型/网络取消不保证撤回请求，但迟到结果不再触发发送；没有自动重试。
- 开场失败/未确认或模型不能生成有效预回复只记录失败，不采用固定角色文案替代。任务状态见/bili status。
- 用户触发的延迟回复不强行打开HDS全局主动消息；无关前台回合最多让路30秒，持续繁忙则终止任务。
- 原HDS其他插件或人工消息不属于此观看任务的去重范围。
