## 常用命令

- 执行/卡片：bili.run <请求>、bili.pick、bili.card <BV> [miniapp|link]、bili.web <网址> [问题]
- 状态/记录：bili.status、bili.history、bili.watched、bili.effects
- 登录/账号：bili.login、bili.login.cancel、bili.logout、bili.check、bili.account、bili.folders
- 确认/取消：bili.confirm <编号>、bili.cancel <编号>
- 公开目标：bili.target；评论暂停/恢复：bili.comments.pause / bili.comments.resume
- 插件暂停/恢复：bili.pause / bili.resume
- 眼镜：看视频 <链接或BV>、eyes.status、eyes.clear

独立模式私聊中，直接转发视频即触发“只评论”；“推荐个B站视频给我”触发选片 + 卡片；其他聊天交给 HDS。
