# 数据清理报告

## 处理对象

从已交付主插件 0.5.6 与眼镜 0.3.0 的源码包（经 SHA256 校验）建立新副本，采用文件白名单打包。不是从生产运行目录导出，也没有连接服务器。

## 已处理

- 清空主插件内置聊天目标和机器人 QQ 默认值；公开评论目标默认本就为空。
- 测试中的原个人 QQ 标识改为虚构 ID；协议十六进制 fixture 内同样替换对应 ASCII 标识。
- 不纳入任何运行数据、缓存、观看/互动账本、数据库、日志、个人配置、会话凭据、备份或 node_modules。
- 不带历史安装脚本中的服务器入口，不内置服务器地址、SSH 信息或生产实例 ID。
- 替换容易混淆的新旧混排 README，建立统一功能入口；保留测试、第三方许可证头部与公共接口常量。

## 刻意保留

- 测试代码内模拟 Cookie/Key、临时 state.json 写入及清理逻辑，用于检验安全与回归；均非真实凭据。
- 公共 BV 示例、测试视频标题、固定公开 API 域名及 QQ 应用 ID；不是私人历史。协议 fixture 用于验证生成/解析，不用于真实登录。
- 运行时数据目录名只是源码常量，目录及其内容不随库交付。

## 不执行
