## 联动测试依赖

联动测试还需在隔离测试工程准备 koishi-plugin-hds-interlude 1.0.1-rc57、koishi-plugin-adapter-onebot 6.9.5、@koishijs/plugin-http 0.6.3、@koishijs/plugin-database-sqlite 4.7.0。设置 NODE_PATH 先指向本库两个包、再指向该工程 node_modules，执行 `npm run test:integration`。不要指向生产工程。

## 使用前仍需现场确认

真实登录、卡片客户端展示与点击、转发识别、自定义模型的回复风格、网页实际可读率、评论审核与@通知都需要现场验证。
