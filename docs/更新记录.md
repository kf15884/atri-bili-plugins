# 更新记录

## 0.5.6
- `videoMaterial` 默认只用标题简介等元信息 + 弹幕 + 热门评论；字幕/画面不交给模型、不写入记忆；`all` 恢复旧行为。
- 模型 JSON 解析容忍思考块、代码块和前言；输出上限 2400 token；降级原因写入 bili.history。
- 提示词参照 Atri 近期真实消息的分条/标点/空格习惯；固定降级句按近期习惯改写。

## 0.5.5
- 卡片只在主动推荐或你索取时发送；转发视频（小程序、结构化分享、b23、链接、BV）只评论，明确索要才回卡片。
- 新增 share.js；修复转发小程序没有 BV 时可能改选别的视频的问题，识别不出就如实说明。
- HDS 模式卡片桥不把 2 小时内转发过的视频转回卡片。
- 取消“合成一句、改逗号句号、180 字截断”，正文分条与标点完全按 HDS，首条与逐条使用 HDS 打字时延。

## 0.5.4
- 删除 DeepSeek 专用搜索/抓取与配置；新增公开网页读取（`webReadEnabled`、`webReadDailyLimit`、`bili.web`），复用现有独立 API。
- 视频可附一个公开网页作为补充，与视频资料同一次请求综合。
- `singleSummaryReply`：综合成一次感想，不逐项回答。

## 0.5.3
- 卡片改用 OneBot 适配器真正编码的 `onebot:json`（6.9.5 会静默丢弃普通 `json`），文字与卡片分别记录回执；负数消息编号视为有效；空回执只记未知，不改发链接或重发。

## 0.5.2
- 回复证据校验：声称完整看完、已执行账号操作或无字幕时声称读到字幕会被拦下，最多重写一次；仍不合格用固定说明，不采用草稿。

## 0.5.1（v1 库基线）
- 独立 API + HDS 人设/格式规则、分段回执与打字时延、卡片单独发送。
