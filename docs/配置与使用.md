# Beta 配置与使用

本手册仅适用于主插件0.7.5-beta.1、眼镜0.5.2-beta.1，不适用于旧独立模型版本。

## 必填与可选配置

1. 在原主插件实例填写本人 `targetUserId`、机器人 `selfId`，接入原HDS服务；不创建重复实例。
2. 眼镜 `autoReadShared=true`、`watchPacing=true`，默认随机等待30–90秒。
3. 看听功能默认关闭。需要时自行部署第二台atri-senses 0.2.0，再开启 `framesEnabled`。
4. `framesUrl` 默认空，格式 `http://<请填写第二台内网地址>:8101`，请用自己的内网地址替换提示文字。
5. `framesToken` 填写自己的第二台鉴权Token，不上传配置文件。
6. `framesScope=shared` 仅处理本人分享；`all` 也处理自主候选。`framesWaitSec=180`；启用后建议眼镜 `taskTimeoutSec=300`。
7. 模型、代理、备用线路在第二台配置，本插件不内置Key，也不要求把Key发送到聊天里。代理格式 `http://<请填写主服务器内网代理地址>:<请填写代理端口>`。

## 使用与限制

本人QQ私聊分享单个BV、B站链接或QQ视频卡片，HDS确认开场后才读取；追问可提前发出已完成草稿。要视频的明确请求由HDS决定发不发。管理指令必须以 `/bili` 开头，只在QQ私聊使用。

插件只读B站，不评论、点赞、投币、关注或发动态；没有旧版独立模型与网页研究模式。开启看听时只分析静止抽帧和开头音频，不代表完整播放。
